\section{VR and Desktop Support}

V12 supports both VR and desktop users within the same scene.

\subsection{Input Abstraction}
All input devices map into a unified interaction layer:
\begin{itemize}
	\item Mouse / Keyboard
	\item VR Controllers
	\item Hand Tracking
\end{itemize}

\subsection{Hands and Avatars}
Hands are first-class scene objects and participate in:
\begin{itemize}
	\item Physics
	\item Interaction events
	\item Network replication
\end{itemize}
