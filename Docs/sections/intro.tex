\section{Introduction}

This document describes the architecture, design philosophy, and systems
behind the \textbf{V12 Engine} and the game \textbf{Tracktor}.

V12 is a real-time, networked 3D engine supporting both desktop and VR
interaction paradigms. Tracktor is a flagship project built on top of V12
to validate engine features and workflows.

This documentation targets:
\begin{itemize}
	\item Engine developers
	\item Game developers
	\item Tooling and editor contributors
\end{itemize}
