\section{Entity Component System}

V12 uses a data-oriented ECS design.

\subsection{Entities}
Entities are lightweight identifiers with no inherent behavior.

\subsection{Components}
Components store structured data attached to entities.

\subsection{Addons}
Addons are sub-components that modify component behavior at runtime.

\begin{itemize}
	\item Addons may inject logic
	\item Addons may modify synchronization rules
	\item Addons may expose editor tooling
\end{itemize}
